# TikTok Ordered Link Selector

This unpacked Chrome extension adds numbered selection controls to TikTok post grids and copies selected video/photo links in the order you chose them. It does not read cookies, contact the downloader, or send links to any remote service.

## Install on Chrome for Windows

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this `chrome-extension` folder.
5. Optionally pin **TikTok Ordered Link Selector** from Chrome's extensions menu.

## Use

1. Open your TikTok Likes page and wait for its grid to appear.
2. Click the extension icon.
3. Select posts individually, or use **Select all loaded**.
4. Continue scrolling. Selections remain ordered even when TikTok recycles off-screen tiles.
5. Click **Copy selected links**.
6. Paste once into TikTok Downloader, enter the start number, and click **Download All**.

Unchecking and rechecking a post moves it to the end of the selection order. Reload the extension from `chrome://extensions` after replacing any extension files, then refresh TikTok.
